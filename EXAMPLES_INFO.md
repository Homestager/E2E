### 📊 ГРАФИК 1 - Сквозная аналитика
**Файл:** `EXAMPLE_chart1_cross_analytics.png`

**Содержание (10 подграфиков):**

1. **Шапка с метриками**
   ```
   ════════════════════════════════════════════════════════════════════════════
                             СКВОЗНАЯ АНАЛИТИКА
           2025-10-20 — 2025-12-04
   ════════════════════════════════════════════════════════════════════════════
    Выручка: 288.1M ₽              ROMI: 930%
    Расходы: 28.0M ₽               CPL: 861 ₽
    Лиды: 32493                    LTV: 33319 ₽
    Продажи: 8646                  Клики: 211258
   ════════════════════════════════════════════════════════════════════════════
      CR(C→L): 15.38%   |   CR(L→S): 26.61%   |   CR(C→S): 4.09%
   ════════════════════════════════════════════════════════════════════════════
   ```

2. **Тепловая карта продаж по дням недели**
   - Показывает в какие дни недели каждая кампания приносит больше продаж
   - Цветовое кодирование: от желтого (мало) до красного (много)

3. **Динамика выручки по кампаниям**
   - Временной график с полупрозрачными кривыми для каждой кампании
   - Столбики общего количества продаж на фоне (серые, полупрозрачные)
   - 4 кампании: BLACKFRIDAY_2025, NEW_YEAR_PROMO, SPRING_SALE, SUMMER_BLAST

4. **Пирог распределения выручки по кампаниям**
   - Показывает долю каждой кампании в общей выручке
   - С процентами и подписями

5. **Динамика выручки по соцсетям**
   - Временной график по соцсетям: Instagram, Telegram, YouTube, VK
   - Полупрозрачные кривые разных цветов

6. **Пирог распределения выручки по соцсетям**
   - Доля каждой соцсети в общей выручке

7. **Распределение бюджета**
   - Два пирога: по соцсетям и по кампаниям
   - Показывает как распределены рекламные расходы

8. **Средний LTV по кампаниям**
   - Горизонтальный барчарт
   - Сортировка от большего к меньшему

9. **Сравнение ROMI и расходов по кампаниям**
   - Вертикальные столбики ROMI (зеленые)
   - Наложенные столбики расходов (оранжевые)
   - Две оси Y

10. **ROMI и CPL по соцсетям**
    - Двойной горизонтальный график
    - ROMI слева (синий)
    - CPL справа (фиолетовый)

11. **CPL по кампаниям**
    - Горизонтальные столбики стоимости лида

12. **CR(C→S) по кампаниям**
    - Конверсия из клика в продажу
    - Горизонтальные столбики в процентах

### 📈 ГРАФИК 2 - Детальная аналитика по кампании
**Файл:** `EXAMPLE_chart2_campaign_BLACKFRIDAY_2025.png`

**Кампания:** BLACKFRIDAY_2025  
**Источников:** 6  
**Период:** 2025-10-20 — 2025-12-04

**Содержание (14 подграфиков):**

1. **Шапка кампании**
   ```
   ════════════════════════════════════════════════════════════════════════════
                              ИТОГИ КАМПАНИИ
                  BLACKFRIDAY_2025 (ID: 1000)
   ════════════════════════════════════════════════════════════════════════════
   | Выручка: 70.1M ₽                   | ROMI: 790%                          |
   | Расходы: 7.9M ₽                    | CPL: 909 RUB                        |
   | Лиды: 8695                         | LTV: 8069 RUB                       |
   | Продажи: 2168                      | Клики: 56440                        |
   ════════════════════════════════════════════════════════════════════════════
   |   CR(C->L):   15.41%   |   CR(L->S):   24.94%   |   CR(C->S):    3.84%   |
   ════════════════════════════════════════════════════════════════════════════
   ```

2. **Выручка по источникам (RID) в динамике**
   - Временной график с кривыми для каждого источника
   - Столбики продаж на фоне

3. **Пирог распределения выручки по источникам**
   - Топ-10 источников по выручке

4. **Выручка по соцсетям внутри кампании**
   - Динамика по Instagram, VK, YouTube, Telegram

5. **Пирог распределения выручки по соцсетям**

6. **Распределение бюджета по соцсетям**
   - Пирог расходов

7. **Распределение бюджета по источникам**
   - Пирог расходов (топ-10)

8. **Средний LTV по источникам**
   - Горизонтальный график (топ-15)

9. **ROMI по источникам с KPI линиями**
   - Вертикальные столбики с цветовым кодированием:
     - Зеленые: ROMI выше положительного KPI (1200%)
     - Красные: ROMI ниже отрицательного KPI (700%)
     - Оранжевые: между KPI
   - Зеленая пунктирная линия: KPI+ (1200%)
   - Красная пунктирная линия: KPI- (700%)
   - Серые столбики расходов на второй оси

10. **ROMI по соцсетям с KPI**
    - Горизонтальный график с цветовым кодированием
    - Вертикальные линии KPI
    - CPL на второй оси (фиолетовые столбики)

11. **CPL по источникам с KPI**
    - Горизонтальные столбики
    - Вертикальные линии KPI CPL
    - Цветовое кодирование по KPI

12. **CAC по источникам**
    - Стоимость привлечения клиента
    - Топ-20 источников

13. **CPA по источникам**
    - Стоимость клика
    - Топ-20 источников

14. **Анализ воронки: CPA → CPL → CAC**
    - Три столбца для каждого источника
    - Синий: CPA (клик)
    - Оранжевый: CPL (лид)
    - Красный: CAC (клиент)
    - **Ключевой график для выявления просадок:**
      - Если CPA низкий, а CPL и CAC высокие → проблема в воронке конверсии
      - Текстовое пояснение на графике

15. **CR(C→S) по источникам**
    - Конверсия клики → продажи
    - Топ-20

16. **CR(C→L) по источникам**
    - Конверсия клики → лиды
    - Топ-20

17. **CR(L→S) по источникам**
    - Конверсия лиды → продажи
    - Топ-20

## 📊 Особенности визуализации

### Временные графики
- Формат дат: ДД.ММ (например, 20.10)
- Поворот меток на 45°
- Сетка с прозрачностью 0.3

### Пироги
- Автоматические проценты (белым жирным шрифтом)
- Начало с 90° (сверху)
- Разные цвета из палитры

### Горизонтальные графики
- Сортировка по значению
- Подписи значений справа от столбиков
- Инверсия оси Y (лучшие сверху)

### Вертикальные графики
- Поворот подписей на 45°
- Подписи значений над столбиками
- Сетка только по оси Y

### Тепловые карты
- Colormap: YlOrRd (желтый → оранжевый → красный)
- Значения в ячейках
- Colorbar справа

## 🔧 Как изменить

### Размер графиков
```python
# В chart1_generator.py или chart2_generator.py
def __init__(self):
    super().__init__(figsize=(20, 28), dpi=120)  # Изменить размер
```

### Цвета
```python
# В base_chart.py
COLORS = {
    'primary': '#ВАШ_ЦВЕТ',
    'secondary': '#ВАШ_ЦВЕТ',
    # ...
}
```

### KPI линии
```python
# При создании кампании
campaign.kpi_romi_positive = 1500.0  # 1500%
campaign.kpi_romi_negative = 800.0   # 800%
campaign.kpi_cpl_positive = 150.0    # 150 ₽
campaign.kpi_cpl_negative = 600.0    # 600 ₽
```

## 🚀 Генерация своих графиков

```python
from analytics_bot.main import AnalyticsReportGenerator
from your_database import load_period_from_db

# Загрузить данные
period = load_period_from_db(days=30)

# Создать генератор
gen = AnalyticsReportGenerator(output_dir='./my_charts')

# График 1
chart1 = gen.generate_chart1(period, 'my_analytics.png')

# График 2 для конкретной кампании
campaign = period.campaigns[0]
chart2 = gen.generate_chart2(campaign, f'campaign_{campaign.campaign_id}.png')
```
