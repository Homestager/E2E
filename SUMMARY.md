# Итоговое описание проекта

## ✅ Что было создано

### 1. Полнофункциональная система аналитики

Разработана комплексная система для генерации аналитических отчетов в виде:
- **PNG графиков** (2 типа: сквозная аналитика и детальная по кампании)
- **Текстовых отчетов** с алертами и сравнением периодов
- **Карточек кампаний** для телеграм-бота

### 2. Структура проекта

```
analytics_bot/
├── models/
│   └── data_models.py          # Модели: Campaign, Source, DailyMetrics, AnalyticsPeriod
├── charts/
│   ├── base_chart.py           # Базовые классы графиков (BaseChart, PieChart, BarChart, HeatmapChart)
│   ├── chart1_generator.py    # ГРАФИК 1 - Сквозная аналитика (10 подграфиков)
│   └── chart2_generator.py    # ГРАФИК 2 - Аналитика по кампании (14 подграфиков)
├── anomalies/
│   ├── detector.py             # Детектор аномалий (10+ типов проверок)
│   └── period_comparison.py   # Сравнение периодов (неделя/месяц)
├── formatters/
│   └── text_formatter.py       # Форматтеры для текстовых отчетов
├── examples/
│   └── generate_sample_data.py # Генератор демо-данных
└── main.py                     # Главный класс AnalyticsReportGenerator
```

### 3. ГРАФИК 1 - Сквозная аналитика

**Размер:** 20x28 дюймов, DPI 120  
**Содержит 10 подграфиков:**

1. **Шапка** - основные метрики (выручка, расходы, ROMI, CPL, LTV, конверсии)
2. **Тепловая карта** - продажи по дням недели и кампаниям
3. **Динамика выручки по кампаниям** - временной график с кривыми + пирог распределения
4. **Динамика выручки по соцсетям** - временной график + пирог распределения
5. **Распределение бюджета** - 2 пирога (по соцсетям и кампаниям)
6. **Средний LTV** - горизонтальный график по кампаниям
7. **Сравнение ROMI** - вертикальные столбики ROMI + расходы по кампаниям
8. **ROMI и CPL по соцсетям** - двойной горизонтальный график
9. **CPL по кампаниям** - горизонтальный график
10. **CR(C→S) по кампаниям** - горизонтальный график

### 4. ГРАФИК 2 - Детальная аналитика по кампании

**Размер:** 20x32 дюймов, DPI 120  
**Содержит 14 подграфиков:**

1. **Шапка** - метрики кампании (форматированная таблица)
2. **Выручка по источникам** - динамика + пирог
3. **Выручка по соцсетям** - динамика + пирог
4. **Распределение бюджета** - 2 пирога (соцсети и источники)
5. **LTV по источникам** - топ-15 (горизонтальный)
6. **ROMI по источникам** - с линиями KPI, цветовое кодирование
7. **ROMI по соцсетям** - с линиями KPI, двойной график с CPL
8. **CPL по источникам** - с линиями KPI
9. **CAC по источникам** - стоимость клиента
10. **CPA по источникам** - стоимость клика
11. **Анализ воронки** - CPA → CPL → CAC (выявление просадок)
12. **CR(C→S) по источникам** - конверсия клики→продажи
13. **CR(C→L) по источникам** - конверсия клики→лиды
14. **CR(L→S) по источникам** - конверсия лиды→продажи

### 5. Система обнаружения аномалий

**10+ типов проверок:**

- 🔥 Резкое падение ROMI (>30%)
- 🚀 Резкий рост ROMI (>50%)
- 🚫 Источник перестал приносить трафик
- ⚠️ Рост CPL (>40%)
- 📉 Падение конверсии (>50%)
- 💤 Бюджет не обновлялся N дней
- 🎯 ROMI ниже KPI
- 🤔 Нет продаж после запуска
- 📊 Корреляция пиков с запуском источников
- И другие...

**Алгоритмы:**
- Скользящее среднее (MA7)
- Z-score для выявления выбросов
- Анализ трендов
- Корреляционный анализ

### 6. Сравнение периодов

**Автоматическое сравнение:**
- Неделя к неделе
- Месяц к месяцу

**Метрики:**
- ROMI
- CPL
- CR(C→S)
- Выручка
- Продажи

**Форматирование:**
- Процент изменения (+/-%)
- Эмодзи индикаторы (📈 📉 ➡️)
- Предупреждения ⚠️ для негативных изменений >10%

### 7. Форматтеры текста

**Функции:**
- Форматирование чисел (с разделителями тысяч)
- Форматирование денег (с M/K суффиксами)
- Форматирование процентов
- Карточки кампаний (для телеграм-бота)
- Списки кампаний
- Шапки отчетов

### 8. Модели данных

**4 основных класса:**

1. **DailyMetrics** - метрики за день
   - Свойства: clicks, leads, sales, revenue, spend, refunds
   - Автоматические расчеты: ROMI, CPL, CAC, CPA, CR(C→L), CR(L→S), CR(C→S)

2. **Source** - источник трафика (RID)
   - Свойства: rid, name, social_network, campaign_id, start_date
   - Список daily_metrics
   - Агрегированные метрики (total_*, avg_*)

3. **Campaign** - рекламная кампания
   - Свойства: campaign_id, name, created_date
   - KPI настройки (romi_positive/negative, cpl_positive/negative)
   - Список sources
   - Методы: get_top_sources(), get_worst_sources()

4. **AnalyticsPeriod** - период аналитики
   - Свойства: start_date, end_date
   - Список campaigns
   - Методы: get_revenue_by_social(), get_spend_by_social()

### 9. Генератор демо-данных

**Функции:**
- Генерация реалистичных данных
- Поддержка сезонности (выходные отличаются)
- Тренды (рост/падение со временем)
- Случайный шум для реалистичности
- Разные качества источников (quality_factor)
- Даты старта источников в середине периода

**Параметры:**
- Количество дней (по умолчанию 30-45)
- Количество кампаний (по умолчанию 3-4)
- Количество источников на кампанию (5-12)
- Поддержка 6 соцсетей: Instagram, Telegram, YouTube, VK, Facebook, TikTok

### 10. Главный генератор отчетов

**Класс AnalyticsReportGenerator:**

**Методы:**
- `generate_chart1()` - сгенерировать График 1
- `generate_chart2()` - сгенерировать График 2
- `generate_text_report()` - сгенерировать текстовый отчет
- `generate_campaign_card()` - сгенерировать карточку кампании
- `generate_full_report()` - сгенерировать все отчеты сразу

**Возможности:**
- Автоматическое именование файлов (с timestamp)
- Создание выходной директории
- Интеграция с детектором аномалий
- Интеграция с компаратором периодов

## 📝 Дальнейшие шаги

### Для использования

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите демонстрацию:

   - Используйте примеры из `USAGE_EXAMPLE.md`
