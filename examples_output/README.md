# 🎨 Примеры PNG Графиков

## Просмотр примеров

### В браузере (рекомендуется)
Откройте файл `VIEW_EXAMPLES.html` в браузере для удобного просмотра с описаниями.

### Прямой просмотр PNG
- `EXAMPLE_chart1_cross_analytics.png` - График 1 (Сквозная аналитика)
- `EXAMPLE_chart2_campaign_BLACKFRIDAY_2025.png` - График 2 (Детальная аналитика)

## Характеристики

### График 1
- **Размер:** 513 KB
- **Разрешение:** 2138 x 2704 пикселей
- **Подграфиков:** 10
- **Данные:** 4 кампании, 26 источников, 45 дней

### График 2  
- **Размер:** 608 KB
- **Разрешение:** 2151 x 3073 пикселей
- **Подграфиков:** 14
- **Данные:** Кампания BLACKFRIDAY_2025, 6 источников

## Создание своих графиков

```bash
# Вернуться в корневую директорию
cd /workspace

# Запустить генератор
python3 test_analytics.py
```

Ваши графики будут созданы в `./analytics_bot/output/`
